# 문서·주석·커밋 작성 컨벤션

hosspie 의 모든 문서·코드 주석·커밋 메시지에 적용되는 룰. (path 없이 항상 로드)

## 언어

모든 사용자 가시 텍스트는 **한글**. 변수/함수명/파일명만 영어.

| 대상                                      | 언어 |
| ----------------------------------------- | ---- |
| `.md` 문서 (README/CLAUDE.md/plans 등)    | 한글 |
| 코드 주석 (`// ...`, `/* ... */`, JSDoc)  | 한글 |
| 커밋 메시지 본문                          | 한글 |
| 사용자 대면 에러 메시지 (UI/GraphQL 응답) | 한글 |
| 변수/함수/파일명/타입명                   | 영어 |

## 코드 주석

- 외부 참조 링크는 `📚` 접두사: `// 📚 참고: https://docs.nestjs.com/providers`
- WHY 만 적기 (WHAT 은 코드가 말함). 자명하면 주석 안 씀
- JSDoc: export + 다회 재사용 코드는 `@example` 포함 (구체 룰은 도메인별 `code-style.md` 참조)

## 계획·설계 문서 위치

- `docs/superpowers/plans/YYYY-MM-DD-<slug>.md` — superpowers 플로우 산출 계획서
- `docs/` 직속 — 일반 설계 문서 (아키텍처, 의사결정 로그)

## 금지

- `.md` 안에 `TODO`/`FIXME` 주석 금지 — 미해결은 GitHub 이슈로
- 이모지 남발 금지 (외부 링크 `📚`, 의도된 강조 외)
- 영문 잡설/AI 보일러플레이트 금지 — 본문은 한글로 짧고 구체적
