# 섹션 정의

이 파일은 Postgres 모범 사례의 규칙 카테고리를 정의합니다. 규칙은 파일명 접두사를 기반으로 자동으로 섹션에 할당됩니다.

아래 예시는 순전히 설명용입니다. 각 섹션을 Postgres 모범 사례의 실제 규칙 카테고리로 교체하세요.

---

## 1. 쿼리 성능 (query)
**영향도:** CRITICAL
**설명:** 느린 쿼리, 누락된 인덱스, 비효율적인 쿼리 플랜. Postgres 성능 문제의 가장 흔한 원인입니다.

## 2. 커넥션 관리 (conn)
**영향도:** CRITICAL
**설명:** 커넥션 풀링, 제한, 서버리스 전략. 높은 동시성 또는 서버리스 배포를 사용하는 애플리케이션에 중요합니다.

## 3. 보안 & RLS (security)
**영향도:** CRITICAL
**설명:** Row-Level Security 정책, 권한 관리, 인증 패턴.

## 4. 스키마 설계 (schema)
**영향도:** HIGH
**설명:** 테이블 설계, 인덱스 전략, 파티셔닝, 데이터 타입 선택. 장기적인 성능의 기반입니다.

## 5. 동시성 & 락킹 (lock)
**영향도:** MEDIUM-HIGH
**설명:** 트랜잭션 관리, 격리 수준, 데드락 방지, 락 경합 패턴.

## 6. 데이터 접근 패턴 (data)
**영향도:** MEDIUM
**설명:** N+1 쿼리 제거, 배치 작업, 커서 기반 페이지네이션, 효율적인 데이터 가져오기.

## 7. 모니터링 & 진단 (monitor)
**영향도:** LOW-MEDIUM
**설명:** pg_stat_statements, EXPLAIN ANALYZE, 메트릭 수집, 성능 진단 사용.

## 8. 고급 기능 (advanced)
**영향도:** LOW
**설명:** 전문 검색, JSONB 최적화, PostGIS, 확장 기능, 고급 Postgres 기능.
