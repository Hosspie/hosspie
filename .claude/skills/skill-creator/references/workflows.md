# 워크플로우 패턴

## 순차 워크플로우

복잡한 작업의 경우 작업을 명확하고 순차적인 단계로 나누세요. SKILL.md의 시작 부분에 프로세스 개요를 제공하는 것이 종종 도움이 됩니다:

```markdown
PDF 양식 채우기는 다음 단계로 이루어집니다:

1. 양식 분석 (analyze_form.py 실행)
2. 필드 매핑 생성 (fields.json 편집)
3. 매핑 유효성 검사 (validate_fields.py 실행)
4. 양식 채우기 (fill_form.py 실행)
5. 출력 확인 (verify_output.py 실행)
```

## 조건부 워크플로우

분기 로직이 있는 작업의 경우 Claude가 결정 지점을 통과하도록 안내하세요:

```markdown
1. 수정 유형 결정:
   **새 콘텐츠 생성?** → 아래 "생성 워크플로우" 따르기
   **기존 콘텐츠 편집?** → 아래 "편집 워크플로우" 따르기

2. 생성 워크플로우: [단계]
3. 편집 워크플로우: [단계]
```
