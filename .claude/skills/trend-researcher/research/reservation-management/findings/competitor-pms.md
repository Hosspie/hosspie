# 경쟁 PMS 현황

## 한국 시장 주요 PMS

### 1. ONDA (온다) 계열

- **펜션플러스**: 펜션/한국형 중소 숙박 특화
- **호텔리어스.구루**: 공유숙박/베케이션 렌탈, 소형 호텔
- **오아PMS**: 모텔, 300실 미만 중소형 호텔
- **다이브**: 대형 호텔 & 리조트
- 특징: 전 영역 포트폴리오, 채널 매니저 기능 포함

### 2. AUTOPUS (오토퍼스)

- 호텔, 펜션, 호스텔, 리조트, 게스트하우스, 모텔 각 타입별 최적화
- 실시간 예약 통합 관리
- 한국어/영어 지원

### 3. 둥지 (Doongzi)

- 호텔, 콘도, 펜션, 게스트하우스, 연수원 등 통합 솔루션
- 별도 설치 없는 웹 기반
- 실시간 예약 확인

### 4. ROONET (루넷)

- 호텔 PMS 특화
- 게스트하우스/호스텔, 펜션/풀빌라 등 규모별 솔루션 제공

### 5. 위홈 (Wehome)

- 공유숙박 특화 (대한민국 1등 공유숙박 표방)
- 네이버 예약 입점 + 운영대행 서비스 제공
- 게스트하우스/한옥스테이 등 소규모 숙박 타깃

### 6. Mobile Calendar

- 게스트하우스를 위한 온라인 예약 시스템
- 모바일 캘린더 기반

## 소규모 게스트하우스 관점의 PMS 한계

| 문제 | 설명 |
|------|------|
| 과도한 기능 | 대부분 호텔/모텔 중심으로 설계, 1~5실 게스트하우스에는 과한 기능 |
| 비용 부담 | 월 구독료가 소규모 업체에게 부담 |
| 학습 곡선 | 복잡한 UI로 IT 비친화적 운영자에게 진입장벽 |
| DM 예약 미지원 | 인스타/카톡 직접 예약을 관리하는 기능 부재 |
| 모바일 미최적화 | 대부분 웹 기반, 모바일 앱 경험 부족 |

## Hosspie 차별화 기회

1. **초소규모 특화**: 1~10실 게스트하우스에 딱 맞는 심플한 UI
2. **모바일 퍼스트**: 운영자가 스마트폰으로 모든 것을 처리
3. **DM/직접 예약 통합**: 인스타/카톡으로 받은 예약을 쉽게 입력·관리
4. **저비용**: OTA 수수료를 내지 않는 업주를 위한 무료/저가 도구
5. **네이버 예약 연동**: 가장 많이 쓰는 저수수료 채널과 통합
