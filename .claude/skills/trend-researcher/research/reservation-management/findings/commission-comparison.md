# 수수료 상세 비교

## 채널별 수수료 구조

### 네이버 예약

| 항목 | 수수료 |
|------|--------|
| 예약 시스템 사용 | 무료 |
| 현장결제 | 0% |
| 네이버페이 온라인결제 | ~3.74% |
| - PG 수수료 | ~3.0% |
| - 네이버 수수료 | ~0.5~0.7% |

- 네이버의 수익모델은 **검색 광고**이므로 예약 수수료는 최소한만 부과
- 10만원 예약 기준 약 3,700원 수수료
- 중개수수료 없음 — PG+결제 수수료만 존재

### 인스타그램 / 카카오톡 직접 예약

| 항목 | 수수료 |
|------|--------|
| 예약 접수 | 0% |
| 계좌이체 결제 | 0% |
| 현장결제 | 0% |

- 플랫폼 수수료 완전 무료
- 단, **운영자의 시간 비용**(DM 응대, 수기 관리, 입금 확인)이 숨겨진 비용

### 야놀자

| 항목 | 수수료 |
|------|--------|
| 기본 중개수수료 | 10% |
| 하위 40% 업체 (한시 인하) | 9% (2025.1~2026.6) |

- 모텔 중심이나 게스트하우스도 입점 가능
- 광고비 추가 부담 가능성 있음

### 여기어때

| 항목 | 수수료 |
|------|--------|
| 기본 중개수수료 | 10% |
| 하위 40% 업체 (한시 인하) | 9% (2024.11~2025.10) |

- 야놀자와 유사한 수수료 구조
- 소규모 게스트하우스에게는 10%가 부담

### 에어비앤비

| 항목 | 수수료 |
|------|--------|
| (구) 분할 수수료 - 호스트 | 3% |
| (구) 분할 수수료 - 게스트 | 14.1~16.5% |
| **(신) 단일 수수료 - 호스트** | **15.5%** |

- 2025년 5월 25일부터 한국 호스트에 단일 수수료 전환
- 기존 1박 20만원 → 약 22.9만원으로 올려야 동일 수익 유지
- 외국인 게스트 유입에는 강점

### Booking.com

| 항목 | 수수료 |
|------|--------|
| 중개수수료 | 15~20% |

- 글로벌 OTA 중 가장 높은 수수료 수준
- 해외 게스트 타깃 시 필수적이나 비용 부담 큼

## 시사점

1. **수수료 격차가 크다**: 네이버 예약(0~3.74%) vs OTA(10~20%)는 3~5배 차이
2. **소규모 업체일수록 직접 예약 의존**: 수수료 부담 때문에 네이버+DM 조합 선호
3. **숨겨진 비용**: 직접 예약의 "무료"는 운영 시간 비용을 포함하지 않음
4. **Hosspie 기회**: 직접 예약 채널의 운영 비용을 낮춰주는 도구 = 저수수료 유지 + 효율화
