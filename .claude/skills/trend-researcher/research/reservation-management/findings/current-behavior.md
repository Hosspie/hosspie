# 현재 예약 관리 행동

## 소규모 게스트하우스 운영자의 예약 처리 플로우

### 네이버 예약 경로

```
게스트가 네이버 검색 → 스마트플레이스에서 예약
  → 운영자: 스마트플레이스센터 앱/웹에서 확인
  → 결제: 네이버페이 온라인 결제 or 현장결제 선택
  → 관리: 네이버 예약 관리 대시보드에서 확인/승인
```

- 네이버 예약은 **modoo(모두) 홈페이지와 연동**하여 운영
- 스마트플레이스센터 앱으로 모바일에서도 예약 확인 가능
- 현장결제 선택 시 수수료 0%, 네이버페이 결제 시 ~3.74%

### 인스타그램 DM 경로

```
게스트가 인스타 프로필 발견 → DM으로 문의/예약 요청
  → 운영자: DM에서 날짜/인원/객실 확인
  → 예약 확정: 계좌번호 안내 → 입금 확인
  → 관리: 수동으로 엑셀/캘린더에 기록
```

- 수수료 0% (계좌이체/현장결제)
- **비정형 데이터**: 대화 형식이라 예약 정보가 구조화되어 있지 않음
- 입금 확인을 수동으로 해야 함 (통장 확인)

### 카카오톡/전화 경로

```
게스트가 카톡 채널 or 직접 전화
  → 운영자: 대화/통화로 예약 확인
  → 계좌이체 or 현장결제
  → 수동 기록
```

## 예약 기록 방식

### 엑셀/구글 시트 (가장 보편적)

기본 관리 항목:
- 예약일자, 체크인/체크아웃 날짜
- 예약자명, 연락처
- 객실(호실), 인원수
- 숙박요금, 기타요금
- 입금 확인 여부
- 예약 채널 (네이버/인스타/카톡/전화)
- 비고 (특이사항)

### 수기 노트/달력

- 극소규모 업체(1~2실)는 종이 달력이나 수첩에 기록하는 경우도 있음

### 네이버 스마트플레이스 대시보드

- 네이버 예약건만 관리 가능
- 다른 채널 예약과 통합되지 않음

## 핵심 불편 사항

1. **이중 입력**: DM/카톡으로 받은 예약을 다시 엑셀에 옮겨야 함
2. **더블부킹**: 네이버에서 예약 들어왔는데 인스타 DM으로도 같은 날짜 예약이 오는 경우
3. **입금 추적**: "입금했어요" → 통장 확인 → 예약 확정 → 회신의 번거로운 과정
4. **노쇼 관리**: 직접 예약(DM/카톡)은 노쇼 시 보호장치 없음
5. **데이터 분산**: 채널별로 예약 데이터가 흩어져 있어 매출/점유율 파악 어려움
