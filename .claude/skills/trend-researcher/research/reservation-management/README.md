# 리서치: 소규모 게스트하우스 예약 채널별 관리 현황 및 수수료 비교

> 조사일: 2026-04-04
> 목적: 네이버 예약/인스타 DM 등 채널별 예약 처리 방식과 수수료 구조 파악
> 활용: Hosspie 예약 관리 기능 설계의 기초 데이터

## 핵심 발견

### 2. 예약 관리 현황

소규모 게스트하우스 운영자의 예약 관리 방식:
- **엑셀/구글 스프레드시트**: 예약일자, 연락처, 객실, 인원, 요금, 입금확인 수기 기록
- **카카오톡/DM 대화**: 예약 확인 → 수동으로 엑셀에 옮겨 기록
- **네이버 스마트플레이스 관리**: 네이버 예약건은 플레이스센터에서 확인 가능하나, 다른 채널과 통합 안됨
- **PMS 미사용 다수**: 소규모 업체는 비용/복잡도 문제로 전문 PMS 미도입

### 3. 핵심 페인 포인트

1. **멀티채널 분산**: 네이버 예약 + 인스타 DM + 카톡 + 전화 등 다채널 예약이 각각 별도 관리
2. **수기 이중 작업**: DM/카톡 예약 → 엑셀 옮기기 → 입금 확인 → 예약 확정 알림
3. **더블부킹 위험**: 채널 간 실시간 재고 동기화 불가
4. **입금 확인 수동**: 계좌이체 예약의 입금 여부를 수동 대조

## 액셔너블 인사이트

- 네이버 예약(3.74%)과 인스타 DM(0%)이 주력 채널인 이유는 **OTA 수수료(10~15.5%)가 소규모 업체에 과도**하기 때문
- → Hosspie는 **저수수료 채널(네이버 예약, 직접 예약) 중심의 통합 예약 관리**에 집중해야 함
- → "OTA 대체"가 아닌 "**OTA 없이 운영하는 업주의 멀티채널 예약 정리 도구**"로 포지셔닝
