## 1. 네이버 예약

### 공식 API 접근성
- 네이버 예약 API는 존재하나 **숙박·행사/축제·스포츠/레저·공연/전시 업종은 공식 연동 대상에서 제외**.
- 일반 업종(미용실·병원·음식점 등)은 계정 연동(1단계) → 상품 연동(2단계)으로 가능하지만, 숙박은 네이버와의 직접 사업 제휴가 필요.
- 연동 프레임 자체가 30분/1시간 슬롯 기반이라 숙박(1박 단위)과 구조적으로 맞지 않음.

### 웹훅·iCal
- 공식 웹훅 없음.
- 네이버 캘린더는 `.ics` 파일 **수동 export**만 지원. 구독형 iCal 링크 제공 안 함.
- 업주 페이지에서 **예약내역 Excel 다운로드**는 가능.

### 현실적 연동 방법
1. 네이버 1644-5690으로 숙박 제휴 문의 (개별 협상).
2. Zapier/IFTTT로 예약 확인 이메일을 파싱해 Hosspie로 전달.
3. 업주가 Excel을 수동 업로드하면 Hosspie가 파싱.

### 소규모 업체 접근성
**매우 낮음**. 제휴 없이는 구조적으로 불가능. 수기/이메일 파싱이 유일한 현실적 경로.

## 2. 야놀자

### 공식 API 접근성
- **외부 개발자용 공개 API 문서·개발자 포털은 확인되지 않음**.
- 야놀자클라우드는 내부적으로 PMS·CMS·BE 솔루션을 API 연동해 글로벌 SaaS로 제공(글로벌 PMS 2위). 그러나 이는 **야놀자클라우드 자체 솔루션을 도입한 고객사** 대상.
- Distribution HUB실이 존재 — Agoda, Expedia, Trip.com, 11번가, 티몬 등과 내부 API 연동 담당.
- 야놀자 파트너센터 앱은 업주 전용. 외부 연동 인터페이스 미공개.

### 웹훅·iCal
- 업주 앱에 푸시 알림(예약·취소·매진). 외부 웹훅 아님.
- iCal 지원 확인되지 않음.

### 현실적 연동 방법
1. **채널매니저(ONDA 등)를 경유** — ONDA는 이미 야놀자와 양방향 연동.
2. 야놀자클라우드 B2B 파트너십 별도 협상.
3. (비권장) 업주 계정 스크래핑 — 약관 위반 소지, 2022년 여기어때의 야놀자 서버 접근 사건 판례 참고 필요.

### 소규모 업체 접근성
**매우 낮음** (직접). 채널매니저 경유 시 **중간**.

## 3. 여기어때

### 공식 API 접근성
- 여기어때 파트너센터(business.goodchoice.kr, business.yeogi.com) 존재. 업주 대상 웹/앱 기반 관리 도구.
- 기술 블로그에 내부 "전시 API" 등 언급되지만 **외부 연동용 공개 API는 확인되지 않음**.
- 2023년 아고다와 B2B API 연동 발표 — 이는 파트너사 간 연동 사례이지 일반 개발자용 API가 아님.

### 웹훅·iCal
- 파트너센터 앱 푸시 알림 (예약·취소·매진 실시간). 외부 웹훅 아님.
- iCal 지원 확인되지 않음.

### 현실적 연동 방법
1. 채널매니저 경유 (ONDA가 여기어때 연동 지원).
2. 여기어때 비즈니스 B2B 제휴 직접 협상.

### 소규모 업체 접근성
**매우 낮음** (직접). 채널매니저 경유 시 **중간**.

## 4. Airbnb

### 공식 API 접근성
- Homes API, Activities API 존재. `developer.withairbnb.com`에 문서 공개.
- 접근은 **Preferred Software Partner** 인증 후에만 가능. 2025년 Preferred+ 파트너 예시: Lodgify, Hostaway, Turno.
- 심사 기준: 데이터 보안, 기술 품질, 통합 기준 등. 신규 신청은 현재 포털에서 일시 일시 중단 상태(글로벌 지원팀을 통해 개별 심사 요청 가능).
- 모든 API 연결 리스팅은 **Instant Book 필수**.

### 기능 범위
- **Limited Sync**: 가격·가용성만 관리
- **Everything Sync**: 리스팅 전체(설명, 사진, 규칙, 예약, 메시지) 관리
- **웹훅**: 예약/리뷰/메시지 실시간 알림 지원 (공식 문서)

### iCal
- **iCal export/import 지원**. 업데이트 주기 **약 3시간**.
- 오버부킹 완벽 방지는 어려움 (시차 존재).

### 현실적 연동 방법
1. **iCal 연동** — 즉시 가능, 인증 불필요. MVP에 최적.
2. Preferred Partner 자격 신청 (장기 전략).
3. 채널매니저 경유 (ONDA는 Airbnb 우수 파트너).

### 소규모 업체 접근성
iCal 기준 **높음**. Full API는 **낮음**.

## 5. Booking.com

### 공식 API 접근성
- Connectivity API 문서 공개 (`developers.booking.com/connectivity/docs`).
- 세 가지 포맷 지원: **OTA XML**, **B.XML**, **JSON**.
- 주요 API: Rooms, Rates, Availability, Reservations, Messaging, Payments.
- **2025~2026 신규 Connectivity Partner 등록 일시 중단** (약관 개정 중). 재개 시점 미정.
- 파트너 요건: 모든 API 기능 지원, 최소 1년치 rate/availability, 사용자 친화 UI, 연동 숙소 지원 의무 등.

### 웹훅·알림
- Messaging API에 **Push Notification 기능 추가 중** (로드맵).
- HotelInvNotif, HotelProductNotif 등 Notification 기반 엔드포인트 존재.
- 2025-12-31 "Basic method" sunset 예정.

### iCal
- iCal export 지원. 단 **조건**:
  - 객실 타입 20개 이하
  - 타입당 1유닛 이하
  - **XML/PMS/채널매니저 연동 중이면 사용 불가**
- 업데이트 2~3시간 지연.

### 현실적 연동 방법
1. **iCal 연동** (소규모·비연동 업체만 가능) — MVP용.
2. 기존 Connectivity Partner(ONDA 등) 경유 — 가장 현실적.
3. 재개 후 자체 Connectivity Partner 신청 (장기).

### 소규모 업체 접근성
iCal 기준 **중간** (조건부). Full API는 **매우 낮음** (등록 중단).

## 6. 비구조적 채널: 카카오톡·Instagram DM

### 카카오톡
- **알림톡/친구톡/상담톡 API**: 발송용. 솔라피·NHN 등 인증 발송대행사 경유.
- **카카오 i 오픈빌더 + Event API**: 챗봇에서 사용자 입력 받아 처리 가능. 단 Hosspie가 **자체 카카오톡 채널**을 운영해야 함 — 게스트가 OTA가 아닌 호스트 채널로 DM 보내는 흐름에만 적용 가능.
- **업주 개인 카카오톡 대화**는 공식 API 접근 불가(정책 위반).

### Instagram
- Instagram Graph API (Meta Business Suite 경유): 비즈니스/크리에이터 계정 DM 수신·발신 가능.
- **24시간 규칙**: 사용자 마지막 상호작용 후 24시간 내에만 자유롭게 발신 가능.
- 댓글 트리거 → 자동 DM 발송 가능 (매니챗, 소셜비즈 등이 활용).
- 앱 심사(Instagram messaging permission) 필요.

### Hosspie 관점
- **직접 DM 파싱 자동화는 제한적**. 자연어로 오는 예약 요청을 구조화하려면 LLM 파싱이 필수.
- 추천 UX: 호스트가 DM 스크린샷 혹은 텍스트를 Hosspie에 붙여넣기 → LLM이 날짜·인원·객실 추출 → 예약 카드 생성. "AI 어시스턴트" 포지셔닝.

## 공통 관찰

1. **"공식 API를 직접 호출"은 소규모 PMS 스타트업에 닫혀 있는 길**. 글로벌 OTA는 Connectivity Partner 심사, 국내 OTA는 아예 공개 API가 없음.
2. **iCal은 "있어도 반쪽짜리"**. 3시간 지연과 기능 제약 때문에 MVP 데모용 이상의 의미를 갖기 어려움.
3. **채널매니저 경유가 현실적 정답**. 특히 ONDA는 소규모 한국 숙박 대상 사실상의 표준.
4. **실시간 알림(웹훅)은 파트너 자격 이후의 혜택**. MVP 단계에서는 주기적 폴링/수기 입력 보조로 대체해야 함.
