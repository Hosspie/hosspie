# 이메일 자동 수신 및 파싱 실현 가능성

## 1. 인바운드 이메일 서비스 비교

예약 이메일을 웹훅으로 받아 NestJS 백엔드에서 파싱하기 위한 SaaS 비교.

| 서비스 | 무료 티어 | 유료 시작가 | 파싱 품질 | 특징 |
|--------|----------|-------------|----------|------|
| **Cloudmailin** | 월 10,000건 무료 | 이후 유료 | 높음 (MIME/첨부 자동 파싱, JSON/Multipart/RAW) | 인바운드 전문, 첨부 S3/GCS 직접 업로드 |
| **Postmark Inbound** | 월 100건 무료 | $15/월 10k건 | 높음 (신뢰성·딜리버러빌리티 최고급) | 발송도 함께 쓰면 편리. 인바운드 단독 저렴 |
| **SendGrid Inbound Parse** | 없음 (Essentials $19.95/월 50k 발송 포함) | $19.95/월 | 중간 | 대규모에 유리, 초기엔 과함 |
| **Mailgun Routes** | 제한적 프리 트라이얼 | $15/월 10k (Basic) + 인바운드 추가 비용 | 중간 | 로그/디버깅 강점, 인바운드 별도 과금 이슈 |
| **AWS SES Inbound** | 프리 티어 포함 | $0.10/1000건 (매우 저렴) | 낮음 (raw MIME만 제공, 파싱 직접 구현) | 가장 저렴하지만 Lambda + 파싱 로직 직접 구축 필요 |

### 1인 개발자 1순위: **Cloudmailin**
- 월 10,000건 무료 → Hosspie MVP 사용자 수백 명까지 커버 가능 (사장님 1명당 월 20~50건 예약 가정).
- 파싱 결과를 JSON으로 바로 받기 때문에 NestJS 웹훅 엔드포인트에서 즉시 처리 가능.
- 첨부파일(PDF 바우처 등)은 S3에 바로 저장되므로 DB 부담 없음.

### 2순위: **Postmark Inbound**
- Hosspie가 향후 사장님 → 게스트 발송(예약 확인, 알림톡 대체)까지 고려한다면 발송+인바운드 통합이 편리.
- $15/월부터 유료이므로 Cloudmailin 대비 초기 비용 발생.

### 비추천: **AWS SES Inbound**
- 가장 저렴하지만 raw MIME을 Lambda에서 직접 파싱해야 함. 멀티파트·인코딩·첨부 처리 코드를 직접 작성하면 수일~수주 개발 비용 소모. 1인 개발자 시간 대비 비효율.

## 2. 채널별 예약 이메일 포맷

### Airbnb
- **포맷**: HTML 이메일, 상대적으로 안정적. 게스트 이름, 체크인/아웃, 인원, 예약 ID, 금액 명시.
- **파싱 검증**: Mailparser, Parsio 등이 **Airbnb 예약 이메일 파싱을 상용 제품화**. GitHub 오픈소스 레시피도 다수.
- **주의점**: Airbnb는 종종 이메일 템플릿을 A/B 테스트/개편함. 정규식 기반 파싱은 깨지기 쉬움 → **LLM 기반 파싱 권장**.

### Booking.com
- **공식 Fallback Email 메커니즘 존재**: Connectivity API 연동 실패 또는 30분 이내 미확인 시 property의 Reservations Contact 주소로 예약 이메일 자동 전송. **즉, 이메일로 받는 게 Booking.com이 인정하는 폴백 채널**.
- 포맷은 HTML + 링크. 예약 세부는 Extranet 링크를 통해 확인해야 하지만, 이메일 본문에 게스트명·일자·방 타입 등 핵심 정보는 포함.
- 타임아웃은 기본 30분, Connectivity Support 요청 시 24시간까지 연장 가능.

### 여기어때 파트너
- 파트너 대시보드에서 예약 알림 수단(이메일/앱 푸시/SMS)을 설정. 이메일 옵션은 존재하나 기본은 앱 푸시/SMS.
- 공개된 이메일 포맷 문서는 없음. 실제 테스트 필요.

### 야놀자 사장님
- 주로 **야놀자 사장님 앱 푸시** 중심. 이메일 알림 옵션은 제한적이거나 보조적.
- 야놀자펜션 사장님 대시보드는 별도 운영.

### 네이버 스마트플레이스
- **2023년 9월부터 SMS 알림이 중단되고 네이버 앱 푸시로 전환**.
- 이메일 알림은 여전히 지원 ("네이버예약 신청이 들어오면 등록된 이메일로 알림"). 단, 사장님이 명시적으로 등록해야 함.
- 포맷은 한국어, 네이버 템플릿. LLM 파싱이 안전.

## 3. 사장님 포워딩 설정 UX

### 시나리오 A: 사장님이 Gmail/Outlook 사용
**실현 가능성: 높음**

1. 사장님이 이미 Gmail 사용 중.
2. Hosspie가 사장님별 고유 인바운드 주소 발급 (예: `host-abc123@inbound.hosspie.com`).
3. Gmail 필터 생성 가이드 제공 (이미지/영상 포함):
   - From: `no-reply@airbnb.com`, `noreply@booking.com`, `bookings@yeogi.com` 등
   - Action: "Forward to: host-abc123@inbound.hosspie.com"
4. Gmail은 포워딩 주소 **사전 인증** 요구 (verification email). Hosspie 백엔드가 자동으로 verification 링크 클릭 처리 → 사장님 UX 간소화.
5. 필터 저장 → 이후 해당 메일이 올 때마다 자동 전달.

**관리 자동화 옵션**: Google OAuth로 사용자 동의받고 **Gmail API로 필터 자동 생성**. 사용자가 버튼 한 번 누르면 필터가 자동으로 만들어짐 → 최고의 UX. 단, Google Workspace 심사(OAuth Verification) 필요.

### 시나리오 B: 사장님이 네이버 메일 사용
**실현 가능성: 낮음**

- **네이버 메일은 외부 주소로의 자동 포워딩 기능을 제공하지 않음**. 보안 정책.
- 우회 경로:
  1. **POP3 가져오기**: 백엔드가 사장님 네이버 메일 계정에 POP3로 접속해서 당겨옴. 사장님 비밀번호 저장 필요 → 보안 리스크 + 2FA 시 불가.
  2. **앱 비밀번호**: 네이버는 외부 클라이언트용 앱 비밀번호 발급 지원. 사장님에게 발급 가이드 제공. UX 복잡.
  3. **권장**: 사장님에게 "예약 전용 Gmail 만들기" 가이드 → Gmail에서 네이버 메일을 POP3로 가져온 뒤 Gmail 필터로 Hosspie에 포워딩. 2단계 구조지만 안정적.

### 시나리오 C: 다음(Daum) 메일
- 다음 메일은 외부 주소 자동 전달 지원. Gmail과 유사하게 필터 구성 가능 (공식 지원 여부/제약은 별도 확인 필요).

## 4. 파싱 전략: 정규식 vs LLM

| 방식 | 장점 | 단점 |
|------|------|------|
| **정규식/XPath** | 빠름, 비용 0, 결정론적 | 템플릿 변경에 취약, 채널별 유지보수 부담 |
| **LLM (Claude/GPT)** | 템플릿 변화에 강함, 다국어/다채널 통합 프롬프트 | 비용($0.001~0.01/메일), latency(1~3초), 가끔 환각 |
| **하이브리드 (권장)** | LLM으로 1차 추출 → 스키마 검증 → 실패 시 사람 확인 큐 | 복잡도 증가 |

**권장**: 멀티채널 API 리서치에서 이미 결론난 "LLM 파싱" 전략과 동일. Claude Haiku/Sonnet로 월 수백~수천 건 파싱하면 비용 $1~$10 수준. 충분히 감당 가능.

프롬프트 예시 구조:
```
시스템: 한국어/영어 예약 이메일을 JSON으로 변환. 스키마: { channel, guestName, checkIn, checkOut, guests, amount, currency, reservationId, raw }.
사용자: <이메일 본문>
```

## 5. 법적 주의

- **개인정보보호법**: 이메일에 포함된 게스트 개인정보(이름·연락처·결제정보 일부)는 사장님의 개인정보 처리 위탁 대상. Hosspie는 위탁처리자로서 이용약관에 수집/이용 고지 필수.
- **사장님의 이메일을 Hosspie가 수신하는 행위 자체**: 사장님 본인 동의 하에 본인 소유 데이터를 전달받는 구조이므로 법적으로 안전한 편. Gmail API 연동의 경우 Google OAuth 스코프 최소화 + Restricted Scope 심사 필요.

---

## 결론

이메일 인바운드 파싱은 **Hosspie M2에서 가장 비용 효율적이고 현실적인 자동 수신 경로**다.
- 커버리지: Airbnb, Booking.com, 네이버(이메일 설정 시), 여기어때(옵션 설정 시).
- 미커버: 야놀자(앱 푸시 중심, 이메일 약함).
- 비용: Cloudmailin 무료 티어 + LLM 파싱 $1~10/월 → 초기 MVP 사실상 무료.
- UX: Gmail 사장님은 필터 자동 생성(OAuth) 또는 수동 가이드. 네이버 메일 사장님은 "Gmail로 갈아타기" 가이드 필요.
