## 포지셔닝 맵

```
           고수수료 (10%+)
              │
  야놀자 ─────┤────── 에어비앤비
  여기어때     │       Booking.com
              │
  ────────────┼────────────────
  소규모 특화  │         대규모/체인
              │
  위홈 ───────┤
  Hosspie(?)  │
              │
           저수수료 (0~4%)
    네이버 예약
    인스타/카톡 직접
```

Hosspie 기회 영역: **소규모 + 저수수료** 사분면 (좌하단)
