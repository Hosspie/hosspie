# Hosspie 제품 컨텍스트

> 이 문서는 리서치 수행 시 Hosspie의 현재 상태를 참조하기 위한 기준점입니다.
> 제품이 발전함에 따라 갱신합니다.

## 제품 정의

- **한 줄 설명**: 게스트하우스 운영자를 위한 모바일 관리 시스템
- **플랫폼**: 모바일 앱 (React Native/Expo)
- **백엔드**: NestJS GraphQL API + Supabase PostgreSQL

## 타깃 사용자

- **1차**: 소규모 게스트하우스/호스텔 운영자 (1~3개 숙소)
- **2차**: 펜션, 민박, 한옥스테이 등 소규모 숙박업 운영자

## 현재 기능 (개발 중)

- 숙소(Guesthouse) 등록 및 관리
- 객실(Room) 등록 및 관리
- 온보딩 플로우 (멀티 스텝 폼)

## 아직 없는 기능 (잠재 리서치 대상)

- 예약 관리
- 게스트 커뮤니케이션
- 매출/통계 대시보드
- OTA(Online Travel Agency) 연동
- 청소/운영 관리
- 리뷰 관리

## 현장 인사이트 (1차 데이터)

> 파운더/사용자로부터 직접 수집한 정보. 리서치의 출발점으로 활용.

- **게스트하우스 예약 채널**: 주로 **네이버 예약**과 **인스타그램 DM** 직접 예약이 핵심 채널
  - → OTA(야놀자/여기어때)보다 네이버 예약 + SNS 다이렉트 예약이 소규모 게스트하우스의 실제 주력 채널일 가능성
  - → 예약 관리 기능 설계 시 네이버 예약 연동 + DM/메시지 기반 예약 정리가 핵심 페인 포인트일 수 있음

## 리서치 시 유의사항

- Hosspie는 초기 단계 — 시장 검증과 PMF(Product-Market Fit) 탐색이 핵심
- 한국 시장 특수성(네이버 예약, 야놀자/여기어때 생태계) 반드시 고려
- 운영자 관점(B2B SaaS)으로 조사, 여행자 관점(B2C)은 보조적으로만 참고
