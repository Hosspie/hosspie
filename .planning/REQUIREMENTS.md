# 요구사항

## 마일스톤 1: MVP — 스태프 관리 플랫폼

#### 1.1 인증 및 온보딩
- 사장님 회원가입/로그인 (소셜 로그인: iOS Apple, Android Google)
- 회원가입 시 역할 선택 (사장님/스태프) → 분기
- 게스트하우스 기본 정보 등록 (이름, 설명, 주소, 연락처, 객실) — **이미 구현됨**
- 스태프 초대: 사장님이 핸드폰 번호 입력 → 초대 링크 SMS 발송 → 앱 다운로드 유도 → 스태프 정보 등록 → 초대 완료
- 역할 기반 접근 제어 (사장님/스태프)

#### 1.2 스태프 근무 일정 관리
- **자동 스케줄 생성**: 근무 일수가 균등하게 분배되도록 랜덤 스케줄 생성
- **스케줄 표시**: 주간/월간 캘린더 뷰로 근무 일정 확인
- **근무 교체 시스템**: 스태프 간 근무 교체 신청 → 사장님 승인/거절
- **알림**: 스케줄 변경, 교체 요청/승인 시 푸시 알림

#### 1.3 인수인계 시스템
- **운영 매뉴얼**: 게스트하우스별 고정 운영 가이드 (체크인 방법, 청소 순서, 비상 연락처 등). 단순 텍스트가 아닌 UI/UX적으로 잘 풀어낸 인터랙티브 매뉴얼
- **일일 인수인계 노트**: "오늘 이런 일 있었어" 식의 교대 시 전달 사항 기록. 다음 스태프가 출근 시 확인

## 마일스톤 2: 게스트 웹 서비스 + 체크인

#### 2.0 게스트 등록 및 진입
- **게스트 등록**: 사장님이 Admin App에서 게스트 정보 수동 등록 (M3 예약 시스템 전까지)
- **SMS 링크 발송**: 등록 시 게스트에게 고유 링크 발송 (핸드폰 번호 기반 인증, 별도 회원가입 없음)
- **링크 유효 기간**: 숙박 기간 동안만 유효. 체크아웃 후 링크 만료 + 기록 삭제

#### 2.1 게스트 체크인
- **QR 체크인**: 게스트하우스 도착 후 QR 코드 스캔 → 체크인 완료 → 오늘의 게스트 채팅방으로 연결
- **Admin 실시간 현황**: 오늘 게스트 목록 + 체크인 현황 자동 추적 대시보드

#### 2.2 게스트 채팅
- 오늘 숙박하는 게스트들끼리 자동 연결되는 채팅방
- 전날 SMS 링크로 접속한 게스트도 채팅 참여 가능
- 사장님/스태프도 참여 가능
- 날짜별 채팅방 자동 생성/아카이브
- **채팅 아카이브 인사이트**: 아카이브 시 자주 추천된 장소, 자주 물어보는 질문 자동 추출

#### 2.3 장소 공유 & AI 코스
- 게스트들이 맛집, 추천 코스를 공유하는 지도 기반 시스템
- 사장님의 추천 장소 등록
- **채팅 아카이브 시 장소 자동 수집**: 언급된 장소를 아카이브 시점에 일괄 추출 → 장소 DB 축적
- **AI 추천 코스 생성**: 축적된 장소 데이터 기반 여행 코스 자동 생성. **구독 게스트하우스 한정**

#### 후순위
- **아이스브레이커 콘텐츠**: 게스트 웹 홈 탭에서 요즘 핫한 대화 콘텐츠나 미니 게임 제공
- 게스트 재방문 추적 + 방문 횟수 기반 레벨 시스템

## 마일스톤 3: 예약 시스템

#### 3.1 숙박 예약 (게스트 웹 → 예약 탭)
- 게스트하우스 탐색 (검색, 필터)
- 게스트하우스 상세 페이지 (소개, 객실, 사진, 리뷰)
- 객실 조회 및 예약
- 예약 확인/취소 플로우
- PG사 연동 결제 (네이버 예약보다 낮은 수수료)

#### 3.2 예약 → 게스트 자동 연결
- 예약 확정 → 게스트 자동 등록 → SMS 링크 자동 발송 (M2 수동 등록을 대체)
- 사장님이 따로 게스트 정보를 등록할 필요 없음

#### 3.3 예약 관리 (Admin)
- 예약 현황 대시보드
- 예약 캘린더 관리
- 객실 가용성 자동 관리
- 예약 알림 (신규 예약, 취소, 변경)

## 마일스톤 4: 스태프 구인구직

> **아키텍처**: 게스트 웹 서비스의 구인구직 탭. 마이크로 프론트엔드로 분리. Admin App에서는 WebView로 구인 화면 import.
> **수익**: 게스트하우스 구독에 포함. "구인→인수인계→스케줄 원스톱"이 핵심 셀링포인트.

#### 4.1 구인 게시 (Admin App → WebView)
- 사장님이 스태프 모집 공고 작성 (근무 조건, 기간, 혜택)
- 지원서 관리 및 면접 일정 관리

#### 4.2 구직 (게스트 웹 → 구인구직 탭)
- 구직자 프로필 등록 및 지원
- 게스트하우스 검색 및 공고 탐색

#### 4.3 채용 연결
- 채용 확정 → Admin App 스태프로 자동 등록 (인수인계 매뉴얼, 스케줄에 바로 연결)

#### 유입 전략
- 게스트 웹 홈 탭의 콘텐츠로 유입 (실시간 핫플, 게스트 대화에서 많이 나오는 장소/주제, 게스트하우스 소개)
- 구직자가 콘텐츠를 보러 왔다가 구인구직 탭도 발견하는 자연스러운 유입

#### 핵심 가치 & 차별점
- **현재 문제**: 네이버 제주도 게스트하우스 카페에서 수동으로 구인구직. 채용 후 별도 시스템에 등록해야 하는 단절
- **Hosspie 차별점**: 구인→면접→채용→인수인계→스케줄까지 끊김 없는 연결. 채용 확정 순간 스태프로 자동 흡수
- **구직자 유입**: 홈 탭 콘텐츠 (핫플, 대화 주제, 게스트하우스 소개)로 자연 유입

## 크로스커팅 요구사항

- **다크 모드 전용**: 현재 디자인 시스템 유지
- **한글 우선**: 모든 UI, 에러 메시지, 문서 한글
- **WebView 하이브리드**: Admin App 화면은 WebView 아키텍처 활용
- **마이크로 프론트엔드**: 게스트 웹은 탭 단위로 마이크로 프론트엔드 분리 (예약/숙박/구인구직)
- **구독 모델**: AI 코스 추천, 구인구직 등 프리미엄 기능은 구독 결제 게스트하우스 한정
