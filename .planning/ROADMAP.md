- [x] Phase 0: 프로젝트 인프라 (완료 — Tamagui→RN StyleSheet 전환, 디자인 토큰, 모노레포 구조)
- [x] Phase 0.5: WebView 하이브리드 아키텍처 (완료 — Vite + Bridge + Home POC)
- [ ] Phase 1: 인증 시스템 (소셜 로그인, 세션 관리, 역할 기반 접근)
- [ ] Phase 2: 스태프 초대 및 관리 (핸드폰 번호 초대, SMS 링크, 스태프 온보딩)
- [ ] Phase 3: 근무 일정 관리 (자동 스케줄 생성, 캘린더 뷰, 교체 요청/승인)
- [ ] Phase 4: 인수인계 시스템 (운영 매뉴얼 에디터, 일일 인수인계 노트)
- [ ] Phase 5: MVP 통합 테스트 및 출시

## 마일스톤 2: 게스트 웹 서비스 + 체크인

> QR 체크인으로 게스트를 자동 연결하고, 채팅과 장소 공유로 게스트 경험을 혁신. 채팅 아카이브에서 운영 인사이트와 장소 데이터를 축적.

- [ ] Phase 6: 게스트 체크인 시스템 (QR 스캔 → 자동 체크인 → 채팅방 연결, Admin 실시간 현황)
- [ ] Phase 7: 게스트 채팅 (자동 채팅방, 실시간 메시징, 아카이브 시 운영 인사이트 추출)
- [ ] Phase 8: 장소 공유 & AI 코스 추천 (지도, 아카이브 시 장소 수집, AI 코스 생성 — 구독 한정)
- 후순위: 아이스브레이커 콘텐츠 (게스트 웹 홈 탭 대화 콘텐츠/미니 게임)
- 후순위: 게스트 재방문 레벨 시스템
